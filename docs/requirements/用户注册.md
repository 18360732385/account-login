# 用户注册

## 背景

单体仓 `account-login` 已具备登录 / 登出 / 改密。需要 **用户注册**，前后端同仓一次交付。

## 范围

### 后端
- `POST /api/auth/register`，body `{username, password}`
- 拒绝重复用户名（409）
- 密码最短 6 位（与改密一致）；用户名非空
- **成功返回与登录相同的 JWT 形状**（`accessToken` / `tokenType` / `expiresInMs`），便于 UX 直接进入已登录态
- 新用户 `displayName` 默认等于 `username`

### 前端
- 注册表单；登录页提供「去注册」链接（注册页可回登录）
- 注册成功后拉取 `/api/me` 并进入已认证视图（与登录成功路径一致）

### 测试
- Java MockMvc 集成：成功 / 重复 / 校验失败
- Vitest：client + App 流程（成功 / 重复 / 校验）
- `mvn -f backend test` 与 `frontend` 下 `npm test` / `npm run build` 全绿

## 非目标
