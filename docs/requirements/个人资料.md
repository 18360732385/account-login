# 新需求：个人资料查看与编辑（前后端）

目标仓：18360732385/account-login（monorepo：backend/ Spring Boot JWT，frontend/ Vite+React），基线分支 harness-e2e-0.7 @ 189fa7f。

## 用户故事
已登录用户可以在“个人资料”页查看自己的账号信息，并修改昵称和邮箱。

## 后端
1. 用户实体新增可选字段 `nickname`（1–20 字符，去首尾空格）和 `email`（合法邮箱格式，全局唯一，可为空）。已有用户迁移后两字段为空。
2. `GET /api/users/me`：需 JWT；返回 `{ username, nickname, email, createdAt }`，不返回密码哈希。
3. `PUT /api/users/me`：需 JWT；请求体 `{ nickname?, email? }`；校验失败返回 400 并给出字段级错误；邮箱被其他用户占用返回 409；成功返回更新后的资料。用户名不可修改。
4. 未登录或 token 失效返回 401（沿用现有鉴权行为）。
5. 单元/集成测试覆盖：正常读取、正常更新、昵称超长、邮箱格式错、邮箱冲突、未登录。

## 前端
1. 新增受保护路由 `/profile`，导航栏在登录后显示“个人资料”入口。
2. 页面展示用户名（只读）、注册时间（只读）、昵称和邮箱（可编辑表单）。
3. 前端做同样的格式校验；提交中按钮禁用；成功提示“资料已更新”；409 时在邮箱字段下显示“该邮箱已被使用”；401 时跳转登录页。
4. 测试覆盖：加载展示、校验提示、提交成功、409 提示、未登录重定向。
