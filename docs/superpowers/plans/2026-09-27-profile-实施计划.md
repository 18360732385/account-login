# 个人资料查看与编辑 实施计划

> **状态：进行中** · feature-eng 主题 `2026-09-27-profile` · Spec：[`../specs/2026-09-27-profile-设计.md`](../specs/2026-09-27-profile-设计.md)

**Goal:** 新增 `GET/PUT /api/users/me` 与前端受保护页 `/profile`，支持查看资料、修改昵称和邮箱。

**Architecture:** 后端新增 `UserController` → `UserProfileService` → `DemoUserStore`（内存），校验在 Service 内聚合为 `FieldValidationException`，由 `GlobalExceptionHandler` 输出带 `fieldErrors` 的 `ErrorResponse`。前端在 `App.tsx` 用 History API 做最小路由，新增 `ProfilePage` / `NavBar`，请求统一经 `api/client.ts`。

**Tech Stack:** Spring Boot 3.3.4 · Java 17 · Spring Security · MockMvc；Vite 8 · React 19 · TS 6 · Vitest 5 · Testing Library。

## Global Constraints

- 后端命令一律仓根 `mvn -q -f backend …`，禁止 `-pl backend -am`（P1）
- 集成测试改共享账号 demo/admin 后必须在 `@AfterEach` 恢复（P2；本主题新增 `resetProfile`）
- REST 变更三处同步：后端 DTO/Controller · `docs/api/modules` 真相 · `frontend/src/api/{client,types}.ts`（P4），**先真相后代码**（rule 12）
- 不引入新依赖（前端无路由库/UI 库/axios/状态库；frontend/AGENTS 禁用清单）
- 错误文案中文且前后端一致：`昵称长度须为 1–20 个字符`、`邮箱格式不正确`、`该邮箱已被使用`、`资料已更新`
- 邮箱正则 `^[^\s@]+@[^\s@]+\.[^\s@]+$`，≤100 字符；昵称按码点计 1–20（trim 后）
- 会话存储 `memory`；不打印 token（P5）

### Task 2: 后端实现 + 集成测试

**Interfaces（Produces）：**
```java
public record DemoUser(String username, String passwordHash, String displayName, int tokenVersion,
                       String nickname, String email, Instant createdAt) {}
// DemoUserStore
public synchronized DemoUser updateProfile(String username, String nickname, String email); // 邮箱被他人占用抛 IllegalStateException
public void resetProfile(String username); // 测试辅助：nickname/email 置 null
// DTO
public record UserProfileResponse(String username, String nickname, String email, Instant createdAt) {}
public record UpdateProfileRequest(String nickname, String email) {}
@JsonInclude(NON_NULL) public record ErrorResponse(String code, String message, Map<String,String> fieldErrors) { ErrorResponse(String code, String message) }
// Service
public UserProfileResponse get(String username);
public UserProfileResponse update(String username, UpdateProfileRequest req); // 400 FieldValidationException / 409 ResponseStatusException
```

- [ ] 先写 `UserProfileApiIntegrationTest`（`@SpringBootTest @AutoConfigureMockMvc`，`@AfterEach` 对 demo/admin 调 `resetProfile`）：
  - `getProfileReturnsEmptyFieldsForSeedUser`：GET 200，`username=demo`，`nickname`/`email` 为 null，`createdAt` 非空，`passwordHash` 不存在
  - `updateProfileTrimsAndPersists`：PUT `{"nickname":"  小明  ","email":" demo@example.com "}` → 200 `nickname=小明`、`email=demo@example.com`；再 GET 一致
  - `updateRejectsTooLongNickname`：21 字 → 400 `code=BAD_REQUEST`、`fieldErrors.nickname=昵称长度须为 1–20 个字符`
  - `updateRejectsInvalidEmail`：`not-an-email` → 400 `fieldErrors.email=邮箱格式不正确`
  - `updateRejectsEmailTakenByOtherUser`：admin 先占 `taken@example.com`；demo 提交 `TAKEN@example.com` → 409 `message=该邮箱已被使用`、`fieldErrors.email`；admin 重复提交自己的邮箱 → 200
  - `profileEndpointsRequireAuthentication`：无 token GET/PUT → 401 `code=UNAUTHORIZED`；伪造 token → 401
  - `usernameInBodyIsIgnoredAndBlankClears`：PUT `{"username":"hacker","nickname":"n1"}` → 200 `username=demo`；再 PUT `{"nickname":"  "}` → `nickname=null`；PUT `{}` 不改 email
