# 设计笔记 — 用户注册（proto 轻量降级 O12）

## 草图
```
[登录] --去注册--> [注册表单]
   ^                    |
   |--去登录------------+
                        | 成功 JWT
                        v
                   [当前用户 Profile]
```

## 主路径 3 步
1. 用户在登录页点「去注册」，填写 username/password（≥6）
2. `POST /api/auth/register` 返回 JWT（同 login 形状）
3. `GET /api/me` → 进入已认证视图

## 备选路径
- 用户名冲突 → 409 文案「用户名已存在」
- 校验失败 → 400 / 客户端拦截
